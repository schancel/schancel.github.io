What ran, and what was modeled

Boundaries matter as much as the numbers

Actual production state and code

  • Independent PeerManager, mempool, address manager, connection manager, known filters and request tracker per actor.
  • Production INV / GETDATA / TX and private reconciliation handlers, codecs, compression, framing and checksum parsing.
  • Real fixed-tick relay, fanout selection, short-ID lookup, pending-response matching, GF(2⁶⁴) recovery, bucket fallback and rate limits.
  • Per-actor RNG seeds; deterministic fixture randomness. Only an admission event changes recorded possession.

Explicit experiment boundaries

  • Admission accepts members of a synthetic legacy-v2 transaction catalog. UTXOs, signatures, fees and v7 witness rules are not validated.
  • Virtual FIFO links: 20 ms one-way latency, 1 MB/s serialization and 1 MB queues. Whole-frame queue rejection is not TCP/QUIC packet loss.
  • Message delivery invokes real ProcessMessage; sockets, receive coalescing and congestion control are not simulated. Handler execution consumes no virtual CPU service time.
  • A ten-millisecond polling cadence services production relay timers. There is no churn, in-run epoch change, network geography or CPU-budget model yet.

What “ABC announcement policy” means here

The pinned ABC 1fb7db17 policy uses a shared inbound Poisson timer, immediate outbound announcements, NoBan bypass, all eligible peers and a batch cap of 35 inventories per configured maximum-block megabyte. The control restores those announcement rules while sharing the optimized engine and request code with Nucleation; it is not the entire unmodified upstream daemon. Its short-ID and reconciliation features are disabled. A fixed-eight fanout setting is not Erlay, and no Erlay result is claimed.

Correctness and build evidence

Fourteen normal C++ cases passed: seven reconciliation-actor cases, four virtual-network cases and three full-PeerManager cases. They cover forced terminal overflow, dropped-queue non-convergence, exact serialization timing, bounded trace semantics, independent mempools, stock outbound timing, inbound Poisson timing and NoBan bypass.

The diagnostic normally compiled the modified net_processing.cpp plus actor sources, linked to 41 immutable older Nucleation fixture/dependency inputs at 81386ab04d. Public virtual ABI and Options layout stay unchanged. This is not validation of the current combined patch stack or every build profile.
